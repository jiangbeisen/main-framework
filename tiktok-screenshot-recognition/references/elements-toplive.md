# 元素识别：LIVE 直播间（toplive）

## 适用范围

当 Stage 1 判定为 `toplive` 时使用本文件。即从 Home Feed 左上角 LIVE 图标进入的某个具体主播的直播间内页。

---

## 页面总体结构

页面从上到下：

1. **顶部主播信息栏**：主播头像 + 昵称 + 粉丝数 + Join 按钮 + 观众头像组 + 观众数 + 下拉箭头 + **右上 X 关闭**
2. **顶部下方活动标签区**：如 "🔥 Daily Ranking" / "🪐 x/y" / "Power-Reg..." 等直播活动/排行标签
3. **直播视频主体**：占屏幕主要面积，展示主播画面
4. **叠加的实时评论/弹幕流**：视频底部浮动的文字弹幕、主播 Host 欢迎语、"N joined" 加入提示
5. **右侧飘动的礼物/爱心动画**
6. **底部直播输入栏**：Type... 输入框 + 笑脸 + 玫瑰 + 礼物 + 分享（取代了标准底部 tab bar）

## 元素清单

### 顶部主播信息栏

#### host_avatar_and_name

- **中文名**：主播头像 + 昵称
- **位置**：顶部左侧
- **视觉特征**：圆形头像 + 昵称文字（可能截断）+ 粉丝数（心形 + 数字，如 "19.6K"）
- **可操作性**：`tap`
- **点击后行为**：进入主播的 profile_other 页面

#### join_button

- **中文名**：Join 按钮
- **位置**：头像昵称右边
- **视觉特征**：橙色胶囊按钮，内含心形 + 加号 + "Join" 文字
- **可操作性**：`tap`
- **点击后行为**：加入主播的粉丝群/订阅该直播
- **用户常见指代**："那个橙色按钮"、"加入"

#### viewer_avatars

- **中文名**：观众头像组
- **位置**：顶部中偏右
- **视觉特征**：几个小圆形头像叠加，旁边是观众数（如 "10+ 10+ 62"）
- **可操作性**：`tap`（打开观众列表）

#### top_dropdown_arrow

- **中文名**：下拉箭头
- **位置**：顶部右侧（X 的左边）
- **视觉特征**：圆形按钮内含向下箭头
- **可操作性**：`tap`
- **点击后行为**：弹出直播操作菜单（分享/举报/静音等）

#### top_close_button

- **中文名**：关闭按钮（X）
- **位置**：顶部最右
- **视觉特征**：X 图标
- **可操作性**：`tap`
- **点击后行为**：退出直播间返回上一页
- **用户常见指代**："右上角的 X"、"关闭按钮"、"退出"

### 活动标签区

#### activity_tag

- **中文名**：直播活动/排行标签（可能多个）
- **位置**：顶部信息栏下方一横排
- **视觉特征**：圆角胶囊，含 emoji + 活动名文字，如 "🔥 Daily Ranking" / "🪐 2/3" / "Power-Reg..."
- **可操作性**：`tap`（打开活动详情）
- **条件性**：有些直播间有、有些没有

> **[待补充]**：识别具体的活动类型（Daily Ranking / Party / Power 等）并给每种单独 slug

### 直播视频主体

#### live_video_canvas

- **中文名**：直播视频画面
- **位置**：屏幕主体
- **视觉特征**：主播的实时直播画面
- **可操作性**：`tap`（暂停弹幕显示？）+ `long_press`（操作菜单）+ `swipe_up/down`（切换到其他直播间）

### 弹幕与实时信息

#### live_chat_stream

- **中文名**：评论弹幕流
- **位置**：视频底部偏上
- **视觉特征**：从下往上浮动的半透明文字条，每条含评论者头像 + 昵称 + 内容
- **可操作性**：`tap` 单条（查看发言者主页或回复）

#### host_welcome_message

- **中文名**：主播欢迎语
- **位置**：弹幕流区域
- **视觉特征**：主播头像 + 昵称 + "Host" 黑色标签 + 欢迎内容文字
- **条件性**：直播刚开始或新用户进入时显示

#### join_notification

- **中文名**："N joined" 加入提示
- **位置**：弹幕流底部
- **视觉特征**：挥手图标 + "N joined" 文字

### 右侧动画

#### floating_hearts

- **中文名**：飘动的爱心
- **位置**：右侧屏幕
- **视觉特征**：不断飘起的红色小心形动画
- **可操作性**：`tap`（长按视频任何位置会连续发送爱心）

### 底部直播输入栏

#### live_input_field

- **中文名**：评论输入框
- **位置**：底部最左
- **视觉特征**：圆角灰色输入框，占位符是 "Type..."
- **可操作性**：`tap`（激活键盘输入）

#### live_emoji_button

- **中文名**：表情按钮（笑脸）
- **位置**：底部偏右
- **视觉特征**：笑脸图标
- **可操作性**：`tap`（弹出表情选择）

#### live_rose_button / live_gift_button

- **中文名**：玫瑰/礼物按钮
- **位置**：底部靠右
- **视觉特征**：玫瑰花图标 / 礼物盒图标（可能有数字角标）
- **可操作性**：`tap`（弹出礼物面板）

#### live_share_button

- **中文名**：分享按钮
- **位置**：底部最右
- **视觉特征**：向右箭头图标 + 数字角标（如 "14"）
- **可操作性**：`tap`

---

## 常见子状态

- **`default`**：默认直播观看态
- **`chatting`**：用户点击输入框后，键盘弹出，输入框激活
- **`gift_panel_open`**：点击礼物后弹出礼物选择面板
- **`paused`**：长按暂停弹幕（某些版本）
