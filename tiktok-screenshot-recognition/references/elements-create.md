# 元素识别：创作页（create）

## 适用范围

当 Stage 1 判定为 `create` 时使用本文件。即从底部 `+` 号进入的创作流程。涵盖拍摄前、拍摄中、编辑、发布前所有子页。

---

## 页面总体结构

Create 页面整体是**深色/黑色全屏工作台**，主体是相机预览画面。布局分 4 个分区：

1. **顶部工具区**：X 关闭 + Add sound（胶囊按钮）+ 右侧纵向工具条
2. **右侧纵向工具条**：翻转/闪光灯/AI Cast 标签/定时/分栏/特效/展开箭头 等
3. **底部录制控制区**：时长选择横排 + 中央大红录制按钮 + 两侧特效/合拍缩略图
4. **最底部模式切换**：左下相册 + POST / CREATE / LIVE 模式切换

## 元素清单

### 顶部工具区

#### close_button

- **中文名**：关闭按钮
- **位置**：顶部最左
- **视觉特征**：白色 X 图标
- **可操作性**：`tap`
- **点击后行为**：退出创作返回上一页（可能弹确认保存草稿）

#### add_sound_button

- **中文名**：添加音乐
- **位置**：顶部居中
- **视觉特征**：灰色胶囊按钮，内含 ♪ 音符图标 + "Add sound" 文字
- **可操作性**：`tap`
- **点击后行为**：弹出音乐选择器（二级页面）

### 右侧纵向工具条（从上到下）

#### flip_camera

- **中文名**：前后摄像头翻转
- **位置**：右侧工具条最上
- **视觉特征**：两个绕圈箭头图标
- **可操作性**：`tap`

#### flash_toggle

- **中文名**：闪光灯开关
- **位置**：flip_camera 下方
- **视觉特征**：闪电图标

#### ai_cast_entry

- **中文名**：AI Cast 入口
- **位置**：右侧工具条中上
- **视觉特征**：白色圆角按钮，含 NEW 小标（绿色/青色）+ "AI Cast" 文字 + "Seedance 2.0" 小字 + 右侧 AI 图标
- **可操作性**：`tap`
- **点击后行为**：进入 AI Cast 创作模式（二级）
- **条件性**：仅特定用户可见（功能放量阶段）

#### timer_entry

- **中文名**：定时录制
- **位置**：AI Cast 下方
- **视觉特征**：秒表/时钟图标
- **可操作性**：`tap`

#### split_screen_entry

- **中文名**：分栏布局
- **位置**：timer 下方
- **视觉特征**：小矩形分格图标
- **可操作性**：`tap`

#### effects_entry

- **中文名**：特效/滤镜
- **位置**：split 下方
- **视觉特征**：闪闪样图标，可能有红色数字角标（未读新特效数）
- **可操作性**：`tap`

#### tools_expand

- **中文名**：展开更多工具
- **位置**：工具条最下
- **视觉特征**：向下箭头
- **可操作性**：`tap`（展开更多次要工具）

### 底部录制控制区

#### duration_tabs

- **中文名**：时长选择 tab 横排
- **位置**：录制按钮上方
- **视觉特征**：横排文字选项 `10m / 60s / 15s / PHOTO / TEXT`（当前选中的用白色圆角底框 + 加粗高亮）
- **可操作性**：`tap` 单项

#### record_button

- **中文名**：录制按钮（大红圆）
- **位置**：底部中央
- **视觉特征**：中央大号红色圆形按钮，带白色细外圈
- **可操作性**：`tap`（开始/结束录制）+ `long_press`（某些模式下按住录）
- **用户常见指代**："红色大圆"、"录制"、"开始"

#### effects_thumbnails

- **中文名**：特效/合拍缩略图
- **位置**：录制按钮两侧
- **视觉特征**：左右各两个小圆缩略（地块图标 / 黑白缩放图 / 两个头像等）
- **可操作性**：`tap`（切换当前特效）

### 最底部模式切换

#### gallery_thumbnail

- **中文名**：相册缩略图
- **位置**：左下角
- **视觉特征**：小方形图标，显示最近一张相册照片的缩略
- **可操作性**：`tap`
- **点击后行为**：打开系统相册选择图片/视频

#### mode_switcher

- **中文名**：模式切换（POST/CREATE/LIVE）
- **位置**：底部中央偏右
- **视觉特征**：横排三个文字 `POST / CREATE / LIVE`，当前选中的**加粗白色**，其他灰色
- **可操作性**：`tap` 单项 + `swipe_left/right`
- **用户常见指代**："底下的 POST"、"CREATE 模式"

## 常见子状态

- **`post_mode_ready`**：POST 模式 + 相机预览中，未开始录制（默认态，最常见）
- **`post_mode_recording`**：POST 模式 + 正在录制，录制按钮变形为暂停/方形，上方可能有录制进度条
- **`post_mode_done`**：POST 模式 + 录制完成，进入预览/编辑态
- **`create_mode`**：切换到 CREATE 模式（与 POST 不同的创作流程，如 AI 生成）
- **`live_mode`**：切换到 LIVE 模式（开直播前的配置页）
- **`photo_mode`**：时长选为 PHOTO（拍照片而不是视频）
- **`text_mode`**：时长选为 TEXT（发纯文字帖）
- **`editing`**：进入后期编辑态——画面会变为带时间轴的编辑器，顶部有 Cancel/Next 按钮
- **`post_page`**：最后一步发布前页——纯表单界面（标题/话题/隐私/可见性/是否允许评论等字段）

> **重要**：以上所有子状态都仍归 Stage 1 的 `create`。但 Stage 2 应在 `sub_state` 字段准确标出当前是哪个子状态，因为不同子状态下可见的元素差异很大。
